here# Contribuer à DevHub

Merci de votre intérêt pour **DevHub** ! 🎉

Toute contribution est la bienvenue : code, documentation, tests, idées, rapports de bugs.

---

## 📜 Code de conduite

En participant, vous acceptez de respecter un comportement **respectueux et inclusif**. Aucune forme de harcèlement ou de discrimination ne sera tolérée.

---

## 🐛 Signaler un bug

1. Vérifiez que le bug n'a pas déjà été signalé dans les [issues](https://github.com/cianneydev/devhub/issues)
2. Ouvrez une nouvelle issue avec le template **Bug report**
3. Décrivez :
   - Les **étapes** pour reproduire
   - Le **comportement attendu**
   - Le **comportement observé**
   - Votre **environnement** (OS, Node.js, version de DevHub)

---

## 💡 Proposer une fonctionnalité

1. Ouvrez une issue avec le template **Feature request**
2. Expliquez :
   - Le **problème** que ça résout
   - La **solution** proposée
   - Les **alternatives** envisagées
